# Planearby ✈️

현재 위치 주변 항공기의 항공사·기종·참고 출도착 공항과 진행 방향을 확인하는 **Vue 3 + Vite + JavaScript + SCSS** 대시보드입니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```sh
npm install
npm run dev
```

사이트가 보이면 위치 권한을 요청하고 바로 조회합니다. 허용한 현재 위치를 기준으로 5초마다 갱신하며 30초 제한은 없습니다. 중지 버튼이나 페이지 종료 시 진행 중인 요청을 취소합니다. 위치가 차단되어 있으면 브라우저 사이트 설정에서 직접 허용해야 합니다. 휴대폰의 위치와 나침반은 HTTPS 또는 localhost에서 사용할 수 있습니다.

```sh
npm test
npm run build
npm run preview
```

## GitHub Pages 배포

```sh
npm run deploy
```

이 명령은 GitHub `origin`에서 배포 경로를 계산하고, 사전 렌더링한 `dist/`를 `gh-pages` 브랜치에 배포합니다. 저장소에 대한 Git push 권한과 인증이 필요합니다. 첫 배포 후 GitHub 저장소 **Settings → Pages → Deploy from a branch → gh-pages / (root)**를 선택하세요.

환경 변수나 별도 서버 배포 없이 실시간 조회가 작동합니다. 브라우저가 무료 `cors.dev` 중계를 통해 `adsb.lol`에 요청하므로 GitHub Pages에서 서버 함수를 실행할 필요가 없습니다. 위치를 허용하면 바로 조회하고 정상 응답 시 5초마다 갱신합니다. 계정·API 키·결제 정보는 필요하지 않습니다.

공개 중계 대신 자체 중계를 사용하려면 `api/aircraft.js`를 함수 호스팅에 배포한 뒤 `.env.pages.local`의 `VITE_AIRCRAFT_API_URL`에 실제 HTTPS API 주소를 설정하고 다시 빌드하세요. 웹사이트 주소나 예시 문구를 넣지 마세요. 이 주소는 공개 값이며 비밀 키가 아닙니다. 로컬 개발은 이 설정과 관계없이 자체 `/api/aircraft`를 사용합니다. Vite preview도 로컬 함수를 제공하지만 정적 빌드의 기본 요청 경로는 공개 중계입니다. 자체 함수 호스팅에는 해당 서비스의 한도가 적용됩니다.

사용자 사이트 저장소(`<owner>.github.io`)는 `/`, 프로젝트 저장소는 `/<repository>/` 경로를 사용합니다. 특정 소유자나 저장소 이름을 코드에 고정하지 않습니다. canonical, Open Graph URL, sitemap과 robots 파일도 배포 주소에서 생성합니다. 커스텀 도메인을 사용하는 경우 `SITE_URL`로 정규 URL을 지정하고 저장소의 Pages 도메인 설정을 맞추세요.

배포 없이 Pages 빌드만 확인하려면 다음 명령을 사용합니다.

```sh
npm run build -- --pages
npm run preview -- --mode pages
```

함수 배포 방식은 [Vercel Node.js 함수 문서](https://vercel.com/docs/functions/runtimes/node-js)를 참고하세요.

## 무료 API와 데이터셋

데이터 API에 계정·API 키·결제 정보를 보내지 않습니다. 개발에서는 로컬 서버 중계를 사용하며, 정적 배포에서는 무료 공개 CORS 중계를 사용합니다.

- **브라우저 Geolocation API:** 위치 권한을 받아 현재 좌표를 확인합니다.
- **adsb.lol:** 항공기 위치·호출부호·기종·진행 방향을 제공합니다. 브라우저 CORS를 지원하지 않아 정적 배포에서는 `https://proxy.cors.dev/https://api.adsb.lol/v2/point/...`로 조회합니다. 개발에서는 이 앱의 `/api/aircraft`가 같은 원본을 중계합니다. 좌표는 소수점 셋째 자리로 반올림해 전달하고, 실제 거리 필터는 브라우저의 원래 좌표로 계산합니다.
- **adsbdb:** 선택한 호출부호의 출발·도착 공항을 직접 조회합니다. 운항 날짜가 없는 참고 노선이며 실제 당일 운항과 다를 수 있습니다.
- **항공정보포털·OpenFlights:** 국내 항공사 이름·IATA/ICAO 쌍은 항공정보포털의 운영 중 항공사 목록을 우선합니다. 해외 항공사와 기종은 OpenFlights 스냅샷을 사용합니다. 공항 이름은 API 응답을 사용하며 수동 항공사·공항 이름 표를 유지하지 않습니다.

[API·데이터셋 상세 설명](docs/data-sources.md) · [스냅샷 출처와 라이선스](assets/data/README.md)

정상 위치 요청은 탭당 분당 최대 12회입니다. 무료 `cors.dev`는 [공식 문서](https://cors.dev/docs)에 IP당 분당 600회, 일일·월간 한도 없음으로 안내되어 있지만 원본 API 한도는 별도로 적용됩니다. 2026-10-28 확인한 `adsb.lol` 응답 헤더에는 초당 4회·분당 60회·일일 500회가 명시되어 있었습니다. 공개 중계의 IP를 여러 사용자가 공유할 수 있으므로 이를 사용자별 500회 보장으로 해석하지 않습니다. 서비스 정책·차단·장애에 따라 조회가 중단될 수 있으며 다른 중계로 자동 전환해 한도를 우회하지 않습니다.

일시적인 429 제한에는 `Retry-After`와 `X-RateLimit-Reset`에 따라 대기 후 재시도합니다. 403은 5분 이상 대기합니다. 429의 활성 정책이 일일 한도이고 잔여량이 0이면 **전체 화면에 “조회 토큰을 모두 사용했어요” 모달**을 표시하고 자동 조회와 진행 중인 요청을 중지합니다. 확인 버튼이나 Esc로 닫을 수 있으며, 같은 페이지에서는 초기화 대기 중 다시 조회해도 요청 없이 모달을 다시 표시합니다. 한도 헤더가 없는 429나 네트워크 장애를 일일 토큰 소진으로 단정하지 않습니다. 오류 화면의 예시 보기는 별도로 가상 항공기 12개를 표시합니다.

## 화면과 조회 동작

- PC는 왼쪽 FIDS·오른쪽 레이더, 모바일과 태블릿(1100px 이하)은 위 레이더·아래 FIDS입니다.
- 밝은/어두운 테마가 FIDS와 플랩에도 적용됩니다. 한국어·영어·일본어를 지원합니다.
- 가장 가까운 항공기를 먼저 선택하고 10초마다 미표시 항공편으로 전환합니다. 직접 선택하거나 자동 전환을 일시정지할 수 있습니다.
- 진행 방향은 3칸(`005`), 거리는 4칸(`05.2` km 또는 `0800` m)으로 표시합니다. 기수는 수신된 지상 진행 방향이며 기체 자세 자체를 의미하지 않습니다.
- 숫자 편명은 4자리로 표시하고, IATA 접두사는 외부 데이터셋의 ICAO 코드로 변환합니다. 예: `OZ123 → AAR 0123`. 코드와 숫자 사이에는 빈 플랩 대신 간격을 둡니다. API 요청에는 원래 호출부호를 사용합니다. 등록번호나 문자 접미사가 있는 호출부호는 원래 값을 유지합니다.
- 출도착 공항이 없으면 같은 크기의 `NON` 플랩과 정보 없음 안내를 유지합니다. 예정 시간 영역과 보드 밖의 조회 안내는 표시하지 않습니다.
- 보드 안내 문구가 없어도 두 줄 높이를 확보해 조회 상태 변경 시 보드가 움직이지 않게 합니다.
- 현재 반경은 `utils/geo.js`의 `SEARCH_RADIUS_KM = 25`입니다. 고도를 제외한 Haversine 수평 거리로 계산합니다.
- OpenFlights로 확인된 에어버스·보잉·봄바르디어 계열만 표시하며 GLEX·헬기·알 수 없는 기종은 제외합니다.
- 30초보다 오래된 위치와 중계 캐시는 표시하지 않습니다. 노선 결과는 최대 6시간, 미등록 결과는 1시간 재사용합니다. 노선 조회 실패는 위치 조회를 중지하지 않습니다.
- 조회 기준 위치는 시작할 때 확인합니다. 다시 조회하면 위치를 새로 확인합니다. 위치를 지속 추적하거나 저장하지 않습니다.
- 배경 탭에서도 조회 타이머를 유지하지만 브라우저·운영체제의 절전 정책으로 간격이 늘어날 수 있습니다. 화면으로 돌아오면 즉시 갱신합니다.
- 휴대폰 나침반은 별도 버튼으로 허용합니다. 수평으로 들고 사용하며 실제 북쪽과 오차가 있으면 수동 방향으로 조절합니다. PC에서도 설정에서 방향을 지정할 수 있습니다.

## 접근성·검색 정보

시맨틱 영역과 제목, 건너뛰기 링크, 키보드 포커스, 레이더 버튼의 음성 설명, 상태·오류 알림, 기본 dialog의 포커스 제한을 적용합니다. `prefers-reduced-motion`에서는 플랩 애니메이션을 생략합니다. 검색을 위한 HTML 사전 렌더링, 언어별 제목·설명·문서 언어, Open Graph, WebApplication JSON-LD, Pages 배포용 canonical·sitemap·robots와 `llms.txt`를 제공합니다. 검색 노출이나 순위를 보장하지는 않습니다.

정확한 좌표는 브라우저 메모리에서만 사용합니다. 근사 좌표가 공개 중계(`cors.dev`) 또는 설정한 자체 중계와 adsb.lol에 전달되므로 해당 제공자의 처리 정책도 적용됩니다. 쿠키·인증 정보·페이지 referrer는 API 요청에 보내지 않습니다. 앱 코드에서 좌표를 localStorage·DB·로그에 저장하지 않습니다. 테마·언어·수동 방향 설정만 브라우저에 저장합니다.

## 프로젝트 구조

참고한 [framework](https://github.com/yheun03/framework)의 파일 배치를 Vue 3 + Vite에 적용했습니다. `~`는 프로젝트 루트입니다.

```text
app.vue, main.js                 앱·스타일 진입점
pages/index.vue                 대시보드·조회·설정
layouts/default.vue             화면 외곽
components/projects/planearby/   항공기 아이콘·분할 플랩
assets/scss/                    공통 변수와 프로젝트별 SCSS
assets/data/                    외부 데이터 스냅샷과 명시적인 예시
utils/flights.js                무료 API·노선 캐시
api/aircraft.js                 Vite·서버리스 공용 위치 중계
utils/geo.js                    거리·방위·반경·갱신 주기
utils/airlines.js, aircraft.js   데이터셋 매칭
utils/deployment.js             GitHub Pages 주소 계산
i18n/                           언어별 문구
scripts/                        빌드·데이터 갱신
tests/                          조회 수명주기·API·거리·코드 매칭 검증
```

실제 응답을 테스트용 예시로 대체하지 않습니다. 오류 화면의 예시 보기는 가상 데이터임을 명시하며 실제 조회와 섞지 않습니다.

```sh
npm run data:update:airlines
npm run data:update:aircraft
```

이 앱은 개인 관측용이며 항행이나 안전 판단용이 아닙니다. 빈 결과가 실제 주변에 항공기가 없다는 뜻은 아닙니다.
